SCREENKEY FIXED - WINDOWS 10 / 11
================================

1. Extract the ZIP file completely (right click -> Extract All).
2. Double click "Start Keyboard.bat".
   This opens the REAL built-in Windows on-screen keyboard (osk.exe),
   so you can type into Chrome, Notepad, etc. without installing anything.

OPTIONAL CUSTOM KEYBOARD
------------------------
- Double click "Start Custom ScreenKey.bat" to try the included
  dark floating ScreenKey with letters, numbers, Shift, Caps,
  shortcuts, and arrow keys.
- The launcher uses the built-in .NET Framework compiler to build
  ScreenKey.exe locally. No downloads required.
- If compiling fails, the launcher displays the error and saves
  it to ScreenKey-build.log, then opens Windows' keyboard.
- If the custom window opens but doesn't type, click in Notepad
  and then try a letter. Administrator-elevated or protected apps
  may not accept simulated input for security reasons.

OTHER OPTIONS
-------------
- Try "Open Touch Keyboard.bat" for Windows' touch keyboard.
- Shortcut: hold Win and Ctrl, then press O.
- You can also search Start for On-Screen Keyboard.

TROUBLESHOOTING
---------------
- Always unzip; do not double-click the BAT file inside the ZIP viewer.
- If Windows blocks downloaded files, check Properties of the ZIP
  and choose Unblock (if present), then extract again.
- For troubleshooting, send the precise message or the text of
  ScreenKey-build.log. You don't need to send passwords or private data.

PRIVACY
-------
- Built-in keyboard is part of Windows.
- Custom ScreenKey is source code (ScreenKey.cs); no telemetry,
  network traffic or key recording included.
